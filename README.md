# pptx

## STM32F103 StdPeriph W6100 SPI Template

This repository contains an **STM32CubeIDE-compatible project template** for  
**STM32F103C8T6** using the STM32 Standard Peripheral Library (StdPeriph) and  
targeting **SPI / W6100** ethernet controller integration.

👉 See [`STM32F103_StdPeriph_W6100/README.md`](STM32F103_StdPeriph_W6100/README.md)  
for full build instructions and project details.
