# TalkTale 투자제안서 PowerPoint 생성기

TalkTale (토크테일) - AI 대화형 동화책 웹서비스 & 스마트 음성펜 플랫폼의 투자 제안서를 PowerPoint(.pptx) 형식으로 자동 생성하는 Python 스크립트입니다.

## 📋 개요

이 프로젝트는 `python-pptx` 라이브러리를 사용하여 **12장의 슬라이드**를 포함한 전문적인 투자 제안서를 자동으로 생성합니다.

## 🎯 생성되는 슬라이드

1. **표지** - 서비스명, 태그라인, 날짜
2. **문제 정의** - 4개의 핵심 문제점 (2x2 그리드)
3. **솔루션 개요** - 5단계 플로우 차트
4. **시스템 아키텍처** - 3개 레이어 (하드웨어, 백엔드, 프론트엔드)
5. **RAG 기반 AI 대화 시스템** - 4단계 파이프라인 및 대화 예시
6. **음성펜 & 웹 연동 시스템** - 4단계 플로우 및 사양
7. **아동 심리 분석 시스템** - 4개 기능 카드 및 대시보드 리포트
8. **비즈니스 모델** - 3개 요금제 (스타터, 프리미엄, B2B)
9. **시장 규모 & 경쟁 우위** - TAM/SAM/SOM 및 4대 경쟁 우위
10. **로드맵 & 마일스톤** - 4단계 타임라인 (2026-2028)
11. **재무 계획 & 투자 요청** - 3개년 매출 전망 및 투자 유치 계획
12. **팀 구성 & 클로징** - 4명 팀 소개 및 연락처

## 🎨 디자인 특징

- **다크 테마**: 모든 슬라이드에 다크 배경 적용
- **악센트 색상**: 각 슬라이드마다 고유한 악센트 색상
- **16:9 비율**: 와이드스크린 프레젠테이션
- **이모지 아이콘**: 시각적 가독성 향상
- **둥근 사각형 카드**: 현대적인 UI 디자인
- **한글 폰트**: 맑은 고딕 사용

## 🚀 설치 방법

### 1. 저장소 클론

```bash
git clone https://github.com/ockum12/pptx.git
cd pptx
```

### 2. 의존성 설치

```bash
pip install -r requirements.txt
```

또는 직접 설치:

```bash
pip install python-pptx>=0.6.21
```

## 💻 사용 방법

### PowerPoint 파일 생성

```bash
python create_talktale_ppt.py
```

실행 후 현재 디렉토리에 `TalkTale_투자제안서.pptx` 파일이 생성됩니다.

## 🤖 GitHub Actions 자동 빌드

이 저장소는 GitHub Actions를 통해 자동으로 PowerPoint 파일을 빌드합니다.

### 워크플로우 실행 시점

- `main` 브랜치에 push할 때
- Pull Request가 생성될 때
- 수동 실행 (workflow_dispatch)

### 빌드된 파일 다운로드

1. GitHub 저장소의 **Actions** 탭으로 이동
2. 최근 워크플로우 실행 선택
3. **Artifacts** 섹션에서 `talktale-presentation` 다운로드
