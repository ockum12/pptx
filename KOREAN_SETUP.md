# Korean (Hangul) Language Support on Raspberry Pi

This guide explains how to install Korean language support on Raspberry Pi to properly render Korean text in PowerPoint presentations generated by this project.

## Overview

The TalkTale PowerPoint generator uses Korean text extensively. To properly display and render Korean characters (Hangul) on Raspberry Pi, you need to install Korean fonts and language support packages.

## Quick Installation

Run the provided installation script:

```bash
chmod +x install_korean_fonts.sh
./install_korean_fonts.sh
```

This script will automatically:
1. Update package lists
2. Install Korean fonts (Nanum family, Baekmuk, UnFonts)
3. Install Korean language support packages
4. Update the font cache
5. Verify the installation

## Manual Installation

If you prefer to install manually, follow these steps:

### 1. Update System

```bash
sudo apt-get update
```

### 2. Install Korean Fonts

```bash
# Install Nanum fonts (recommended)
sudo apt-get install -y fonts-nanum fonts-nanum-coding fonts-nanum-extra

# Install additional Korean fonts
sudo apt-get install -y fonts-unfonts-core fonts-baekmuk
```

### 3. Install Korean Language Support

```bash
sudo apt-get install -y language-pack-ko language-pack-ko-base
```

### 4. Update Font Cache

```bash
sudo fc-cache -fv
```

### 5. Verify Installation

```bash
# List all Korean fonts
fc-list :lang=ko

# Check for Nanum fonts specifically
fc-list :lang=ko | grep Nanum
```

## Using Korean Fonts in python-pptx

### Font Substitution for Raspberry Pi

Many Python scripts and applications use Windows-specific Korean fonts like '맑은 고딕' (Malgun Gothic) or '돋움' (Dotum), which are not available on Raspberry Pi. Replace these with NanumGothic for compatibility:

```python
# Windows fonts (not available on Raspberry Pi)
p.font.name = '맑은 고딕'  # Malgun Gothic
p.font.name = '돋움'       # Dotum

# Recommended for Raspberry Pi
p.font.name = 'NanumGothic'  # Modern sans-serif
p.font.name = 'NanumMyeongjo'  # Serif font
```

### Font Usage Example

```python
from pptx import Presentation
from pptx.util import Pt
from pptx.dml.color import RGBColor

prs = Presentation()
slide = prs.slides.add_slide(prs.slide_layouts[0])

# Add Korean text
title = slide.shapes.title
title.text = "안녕하세요"  # Hello in Korean

# Set Korean font
title.text_frame.paragraphs[0].font.name = 'NanumGothic'
title.text_frame.paragraphs[0].font.size = Pt(44)
title.text_frame.paragraphs[0].font.color.rgb = RGBColor(0, 0, 0)

prs.save('korean_test.pptx')
```

## Testing Korean Font Support

Create a simple test script to verify Korean fonts are working:

```bash

cat > test_korean.py << 'EOF'

# Run test
python3 test_korean.py
```

If the script runs without errors and creates `korean_test.pptx`, your Korean font support is working correctly.

## Troubleshooting

### Problem: Korean text appears as boxes or question marks

**Solution**: Ensure Korean fonts are installed and font cache is updated:
```bash
sudo apt-get install fonts-nanum
sudo fc-cache -fv
```

### Problem: Font not found error in python-pptx

**Solution**: Check available fonts and use the exact font name:
```bash
fc-list :lang=ko | grep -i nanum
```

Use the exact font name shown in the output (e.g., 'NanumGothic', not '나눔고딕').

### Problem: Script fails with encoding errors

**Solution**: Ensure your Python script uses UTF-8 encoding:
```python
# -*- coding: utf-8 -*-
```

And run Python with UTF-8 locale:
```bash
export LANG=en_US.UTF-8
export LC_ALL=en_US.UTF-8
python3 your_script.py
```

### Problem: Installation fails on Raspberry Pi

**Solution**: Update your system first:
```bash
sudo apt-get update
sudo apt-get upgrade
sudo apt-get install -f
```

Then retry the installation.

## Locale Configuration (Optional)

To fully support Korean input and display, you may want to configure Korean locale:

```bash
# Install Korean locale
sudo apt-get install locales

# Generate Korean locale
sudo locale-gen ko_KR.UTF-8

# Update locale (optional - this changes system language)
# sudo update-locale LANG=ko_KR.UTF-8
```

**Note**: Changing the system locale to Korean will change your system language. Only do this if you want Korean as your system language.
